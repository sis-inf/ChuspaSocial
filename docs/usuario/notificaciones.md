# Cómo silenciar las notificaciones
## Paso 1
haz clic en tu **icono de usuario** y luego un clic en **preferencias**.

![Menu de preferencias](paso1.png)
## Paso 2
En cuenta de usuario haz un clic en **Preferencias de notificaciones**.

![Preferencias de notificaciones](paso2.png)
## Paso 3
Aqui puedes modificar las notificaciones que recibirás.
## Tipos de notificación

| Tipo | Descripción / Cuándo se envía | Canales por defecto |
| :--- | :--- | :--- |
| **Nota publicada** (`gradepublished`) | Se envía cuando se publica una calificación o nota. | Ventana emergente (popup) y correo |
| **Nuevo seguidor** (`newfollower`) | Se envía cuando un nuevo usuario comienza a seguirte. | Ventana emergente (popup) y correo |
| **Nuevo comentario** (`newcomment`) | Se envía cuando alguien realiza un comentario en tu contenido. | Ventana emergente (popup) y correo |
| **Nuevo reporte** (`newreport`) | Se envía cuando se genera un nuevo reporte o informe. | Ventana emergente (popup) y correo |
