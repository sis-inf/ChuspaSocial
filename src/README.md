# ChuspaSocial (local_chuspasocial)

Plugin local de Moodle que convierte el Dashboard en un muro social académico y agrega un marketplace de libros entre los miembros de la institución.

## Requisitos

- Moodle 4.5 LTS
- PHP 8.1 – 8.3
- Base de datos compatible con Moodle (MariaDB/MySQL o PostgreSQL)

## Instalación desde un archivo zip

1. Comprime el plugin en un archivo zip cuyo directorio raíz se llame `chuspasocial`.
2. Inicia sesión en Moodle como administrador.
3. Ve a **Administración del sitio > Extensiones > Instalar plugins**.
4. Sube el archivo zip y haz clic en **Instalar plugin desde archivo ZIP**.
5. Confirma la instalación y sigue la pantalla de actualización de la base de datos.
6. Purga las cachés desde **Administración del sitio > Desarrollo > Purgar todas las cachés**.
